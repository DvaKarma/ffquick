# ffquick

Atalhos de ffmpeg (cortar, audio, gif, reduzir) com modo --dry.

## Uso

```
python3 ffquick.py --dry cortar in.mp4 00:00:05 00:00:10 out.mp4
```

## Testes

```
python3 test_f.py
```
